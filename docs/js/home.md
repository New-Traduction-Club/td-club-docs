# Welcome to the Just Sayori Wiki!

This wiki is your primary source for information about the **Just Sayori** mod. Whether you're a player looking to get started or a developer wanting to contribute, you'll find what you need here.

If you are experiencing issues with the mod, please check our [issues page](https://github.com/New-Traduction-Club/justsayori-mod/issues) before opening a new one.
