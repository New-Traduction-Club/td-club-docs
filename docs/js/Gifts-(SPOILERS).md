# Gifting to Sayori

There are currently no "clothing" gifting options available.
But gifts do exist.

The currently registered gifts are:

* Otter plush (`otter.gift`)
* Cookies (`cookies.gift`)
* Yum (`yum.gift`)

To gift these, simply add the gift file (e.g. `otter.gift`) into the `gifts` folder in your game's root directory.
Then ask her to check for a gift!

> Note: `chibi` is still an internal visual state in legacy code, but there is no built-in `chibi.gift` registration in the current gifting implementation.
