# `aff_log`

Este archivo contiene un registro de auditoría de cuándo se gana o se pierde afecto. También sirve como registro de sesión.

Este archivo se encuentra en la carpeta `log` de tu instalación de MAS.

Ruta de ejemplo: `<MAS Install>/log/aff_log.log`

Consulta [aquí](./FAQ.md#how-to-view-your-log-files) más información sobre cómo encontrar este archivo.

# `ev_dump`

Este archivo contiene tiempo de sesión, además de datos resumidos de temas y estadísticas menores de temas.

### Unstable
Si estás usando `unstable`, este archivo se generará en la carpeta de tu instalación de MAS.

### Normal
Si **no** estás usando `unstable`, tendrás que seguir estos pasos:

1. Crea un archivo de texto vacío llamado `givedata.txt` en la carpeta de tu instalación de MAS.
2. Inicia y cierra MAS.
3. El archivo debería generarse en la carpeta de tu instalación de MAS.

Ruta de ejemplo: `<MAS Install>/ev_dump.log`

# `submod_log`

Este archivo contiene mensajes generales registrados por los submods que tengas instalados.
También informa de todos los submods instalados (registrados por el framework de submods), junto con su número de versión.

Este archivo se encuentra en la carpeta `log` de tu instalación de MAS.

Ruta de ejemplo: `<MAS Install>/log/submod_log.log`

Consulta [aquí](./FAQ.md#how-to-view-your-log-files) más información sobre cómo encontrar este archivo.
