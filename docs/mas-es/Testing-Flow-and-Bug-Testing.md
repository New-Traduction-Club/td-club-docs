# Flujo de pruebas / Pruebas de errores
Esta es una sección aparte de la página de [Guía de contribución](./Contributing-Guidelines.md). Aquí encontrarás una pequeña guía para probar lo que quieras implementar relacionado con errores y otros problemas, algo fundamental antes de enviar una Pull Request al repositorio.

## Configuración
### Herramientas
No se puede trabajar sin herramientas, ¿verdad? Aquí tienes una lista de herramientas sencillas pero eficaces que puedes usar para probar y corregir errores.

#### Editores de texto
[Atom](https://atom.io/) - Uno de los editores de texto más utilizados por las personas que contribuyen a MAS. *Atom* cuenta con muchas herramientas y funciones que permiten trabajar de forma eficiente y ordenada en los archivos que se están editando. Incluso tiene herramientas para *resolver conflictos de fusión.*

[Microsoft Visual Studio Code](https://code.visualstudio.com/) - Es ligero y solo tarda unos minutos en instalarse. Muy recomendable para escribir diálogos.
  

#### Herramientas obligatorias
[Ren'Py](https://renpy.org/) - Ren'Py es obligatorio para ejecutar el código fuente fuera de una versión publicada, lo cual es necesario para probar lo que quieras añadir en relación con errores y otros problemas.
