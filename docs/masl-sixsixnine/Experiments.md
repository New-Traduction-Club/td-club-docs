This experimental feature allows you to run Ren'Py games using the 6.99 version of the engine. However, we do not guarantee compatibility with all Ren'Py 6.99 games.

You need to put the games in their own folder on [Internal Files](./Virtual-Desktop.md#browse-internal-files).
For example, you can play [_Doki Doki Literature Club!_](https://ddlc.moe/) by downloading the Windows zip file, selecting the `Import Zip` option on File Explorer and running the game on the Experiments screen.

You can have up to three games running at the same time, including MAS.

Installing DDLC mods will be the same method as PC: Put mod files on a clean DDLC.

Here are a few titles that we have tested:

- [Doki Doki Literature Club!](https://ddlc.moe)
- [Monika After Story](https://www.monikaafterstory.com/) (official PC version):
    Note that if you decide to use the official version, you won't be able to play chess or get notifications to work, but everything else will function properly.
- [Just Natsuki](https://justnatsuki.club/) (official PC version)
- [Just Natsuki - JNL version](https://github.com/New-Traduction-Club/NatsukiModDev-Unofficial-Android):
    As official MAS, it will not be 100% compatible with Android. You can download the JN version used on [JNL](https://github.com/New-Traduction-Club/JustNatsuki-Android-port) and run it on MASL 6.99.
- [Doki Doki Exit Music](https://dokimods.me/mods/exit-music)
- [Doki Doki SNAFU](https://dokimods.me/mods/snafu/)

## Saves location

Rather than MAS installed with MASL, all extra games will save their `saves` folder in their own folder.

For example, if you have DDLC on `DDLC-1.1.1-PC`, its `saves` folder will be `DDLC-1.1.1-PC/saves/`.
