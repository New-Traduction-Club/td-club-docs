# Compatibility with Submods

The compatibility for submods will be the same as official MAS version or the MAS version that we have edited, both running on MASL 6.99.

> Note that to have the same compatibility on the official MAS, you need to copy `cacert.pem` from `InternalFiles/monikaafterstory-masl-edition/game/python-packages/certifi/` to `YourMASInstallation/../certifi/`. This solves an SSL bug that appears on Android. This is the only action required, as an sslwarp error was resolved internally in the bundled Ren'Py runtime of the app.

Here is a list of some compatible Submods with MASL 6.99, it can exist more and be compatible.

Submods that require APIs, internet connection:

- MAICA Text-to-Speech Submod (MTTS)
- [MAICA](./Maica.md)
- Submod Updater Plugin
- Autosave Submod

Submods that modify the User Interface:

- ComfyUI
- Emerald Box
- Font Switcher

Submods that enhances and/or expands the user experience with Monika:

- Extra+
- Auto Outfit Change
- Kiss Button
- Noises Submod
- Selector City
- Watching TV Together
- Under the Same Blanket
- Sing Duet with Monika

Dialogue submods such as:

- Drinking Coffee with Monika
- Health Awareness Submod
- Memories of Self-Care & Literature Submod
- Mental Disabilities/Health Submod
- Monika Explains DDLC Lore
- Custom Compliments
- Custom Calendar Dates
- Study With Monika
- MonikaRPG
- Dale's Out and About
- Dale's Little Box of Feelings
- Bed Submod
- Little Bit of Everything
- Random Location Submod
- Sharing Meals with Monika

Submods not compatible:

- Shimeji:
  Due it requieres Java to run it.
  
> And -virtually-, absolutely every submod that can be released after MASL 6.99’s release.

#### Notes

This list refers to tested submods only on MASL 6.99.
If you want a list of which submods support the original MASL, see this: [Reddit post](https://www.reddit.com/r/MASFandom/comments/1pklmyb/compilation_of_all_the_submods_i_h)

However, if a submod is compatible with MASL, it can be with MASL 6.99 as well. We just haven't tested all of them.
